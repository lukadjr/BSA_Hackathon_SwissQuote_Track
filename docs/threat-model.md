# Threat model — à compléter pendant les POCs

Référence : section 11 du [README](../README.md), qui contient la matrice initiale.

Documenter les frontières téléphone / API / guardians / RPC-bundler et les résultats des tests : compromission de l'app, payload malveillant, rejeu, collusion, perte de clés et indisponibilité institutionnelle.

À renseigner pour chaque POC : menace, contrôle effectivement testé, preuve, risque restant. Le recovery ne bloque pas les dépenses de l'owner encore valide ; une session bancaire seule ne suffit pas à autoriser une récupération.
